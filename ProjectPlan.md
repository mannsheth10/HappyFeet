Dataset Information:

County Based Health Statistics (Data Set 1): Our first dataset is a dataset provided by Data.gov and provides health statistics of different communities across the United States. The data provides health information on areas in all 50 states and the District of Columbia and provides different health statistics about the specific county. The provided information highlights statistics on different health diagnoses like high blood pressure, obesity, diabetes, cancer, and more. These statistics are presented on a county by county basis and give insight as to the percentage of people in an area with different health problems. With this information, we hope to determine the percentage of people who are obese or have diabetes and use this information in unison with the other datasets to answer our research question. Each county has a unique Federal Information Processing Code, also known as a FIPS code. This code is unique to every county in America and can be used as a unique identifier for every county. More information as well as a the downloadable file of the data can be found here: https://data.cdc.gov/500-Cities-Places/PLACES-County-Data-GIS-Friendly-Format-2025-releas/i46a-9kgh/data_preview

County Based Food Access (Data Set 2): Our next dataset is provided by the U.S. Department of Agriculture. In this dataset, each observation is a different county and provides us information on the food environment within that county. It provides us information as to the demographics of that area as well as statistics about the access that residents of that county have to different types of food. Alongside traditional demographic data, it provides information on different groups of people’s access to food like children, elderly, people without cars, overall food access and more. This information can be used to determine the access of people in certain counties to food and can be compared to the other datasets by utilizing the FIPS Code to answer our research question. More information as well as a download to the data can be found here: https://www.ers.usda.gov/data-products/food-environment-atlas/data-access-and-documentation-downloads

County Based Income Level (Data Set 3): The last dataset we will be utilizing is provided by Census.gov. In this dataset, we get access to economic data of different counties throughout the country. In this data, it provides information from 2020-2024 as to the poverty levels grouped by age and median household income alongside additional statistics of income allowing us to get an understanding of the income level of people in this specific county. By using this data, we will be able to see the average income of households in a specific county and compare it to data about health and access to food in other datasets to answer our research question. For each observation, a FIPS code is available allowing us to use this data in unison with the other datasets. For more information about this dataset as well as directions to access an API for this data can be found here https://www.census.gov/data/developers/data-sets/acs-5year.html


Unique Identifier: For all datasets, they provide a FIPS code for each county. A FIPS code also known as a  Federal Information Processing Code is unique and standardized code to each county and can be used to match each observation to an observation found in a different dataset. This is how we will join datasets together and is our unique identifier.
