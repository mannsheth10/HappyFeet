## Shuvam Sinha Status Report Contribution

My part of milestone 3 was the USDA Food Environment Atlas. I wrote [scripts/acquire_fea.py](scripts/acquire_fea.py) to download the Atlas's 2025 county-level CSV files directly from the USDA website. The script stores the zip file as [data/raw/fea_county_2025.zip](data/raw/fea_county_2025.zip) and records where and when it was downloaded, along with a SHA-256 checksum, in [data/raw/fea_manifest.json](data/raw/fea_manifest.json). Running the script again checks the saved file against that checksum, so we can tell if the raw data ever changes.

I wrote about the quality of the Atlas data in [docs/fea_quality_pre.md](docs/fea_quality_pre.md) and then did the data cleaning in OpenRefine. The original file lists every variable for every county on separate rows, so I filtered it down to the rows that include the 8 variables our research question needs and reshaped the data set so each county is a single row. I turned the Atlas's missing-value codes into blank cells and dropped the obesity variable after finding it was a state-level figure. For Connecticut, the dataset uses the state's old counties, but our other two datasets use the planning regions that replaced the old counties, so those 8 rows were removed and listed in [data/processed/fea_excluded.csv](data/processed/fea_excluded.csv). The finished dataset is [data/processed/fea_clean.csv](data/processed/fea_clean.csv), and every OpenRefine step is saved in [data/openrefine_history/fea_operations.json](data/openrefine_history/fea_operations.json) so the cleaning can be repeated. Once my file was finished, I handed it to Vansh to merge with the PLACES and Census data. I then updated the status report to reflect my cleaning of the Food Environment Atlas dataset.

My acquisition and cleaning write-up can be found in [status_report.md](status_report.md).
